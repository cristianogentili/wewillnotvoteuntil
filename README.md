# We Will Not Vote Until / Non voteremo finché

A civic manifesto by Cristiano Gentili, published under a [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) licence.

Website: https://wewillnotvoteuntil.org

## Translating the manifesto

Translations into any language are welcome. The English text is the reference version for translators.

1. Download the English text from the website.
2. Translate it in full, keeping the ten conditions and their structure intact.
3. Open an *issue* in this repository, or write to INSERISCI-EMAIL, attaching your translation and telling us the language and how you would like to be credited.

Please keep these fixed phrases consistent across translations:

- *We will not vote until* (title)
- *Power does not fear our anger. It fears our arithmetic.*
- *Consent is earned.*
- *None of the Above* (the ballot option)

## Tradurre il manifesto

Le traduzioni in qualsiasi lingua sono benvenute. Il testo di riferimento per i traduttori è quello inglese; chi traduce dall'italiano può usare direttamente l'originale.

Per proporre una traduzione, apri una *issue* in questo repository o scrivi a INSERISCI-EMAIL, allegando il testo e indicando la lingua e come desideri essere citato.
